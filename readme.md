# プライバシーポリシー

**衛生Pass**（以下、「本アプリ」）は、ユーザーのプライバシーを尊重し、個人情報の適切な取り扱いに努めます。本プライバシーポリシーは、本アプリにおける情報の収集・利用・管理方針について説明するものです。

適用バージョン: 3.0.0 以降

---

## 1. 収集する情報

本アプリは以下の情報を収集・利用します。

### アプリ内で収集する情報
- **学習データ**：問題への回答履歴、正誤記録、苦手フラグ（ブックマーク）
- **設定情報**：文字サイズ設定、学習グレード（第1種・第2種）設定

これらの情報はすべてお使いの端末内（ローカルデータベース）にのみ保存され、外部サーバーへ送信されることはありません。

### 第三者サービスが収集する情報

本アプリは以下の第三者サービスを利用しており、各サービスのプライバシーポリシーに基づき情報が収集される場合があります。

#### Firebase Analytics（利用状況分析）
本アプリでは、アプリの利用状況を把握し、学習体験や機能品質を改善するために、Google LLC が提供する Firebase Analytics を利用する場合があります。

Firebase Analytics では、アプリの起動、学習開始、回答、学習完了、模試開始、模試完了、課金導線表示、購入開始、購入完了、レビュー依頼条件到達など、アプリの利用状況に関するイベントを送信することがあります。

Firebase Analytics に送信する情報は、アプリ識別子、アプリバージョン、ビルド番号、学習モード、選択中の級、分野ID、回答の正誤、問題数、模試スコア帯、課金導線の表示元、レビュー依頼候補トリガーなどに限定します。

Firebase Analytics には、問題本文、選択肢本文、解説本文、自由入力、記述答案、氏名、メールアドレス、個別相談内容、RevenueCat SDK Key、AdMob ID、Apple の決済識別子の生値、question_id、広告IDを送信しません。

本アプリで利用する Firebase サービスは Firebase Analytics のみです。Firebase Auth、Firestore、Realtime Database、Cloud Functions、Storage、BigQuery export、Crashlytics、Remote Config、App Check、Cloud Messaging、Firebase AI Logic は使用しません。

Firebase Analytics により収集される情報は、Google のプライバシーポリシーおよび Firebase の規約に従って取り扱われます。

- Google プライバシーポリシー: [https://policies.google.com/privacy](https://policies.google.com/privacy)
- Firebase におけるプライバシーとセキュリティ: [https://firebase.google.com/support/privacy](https://firebase.google.com/support/privacy)

#### Google AdMob（広告配信）
無料ユーザー向けに広告を表示するため、Google AdMobを利用しています。AdMobは広告配信のために以下の情報を収集する場合があります。

- デバイス識別情報（広告ID等）
- IPアドレス
- アプリの使用状況

AdMobのプライバシーポリシー：[https://policies.google.com/privacy](https://policies.google.com/privacy)

なお、本アプリではパーソナライズ広告を無効化し、非パーソナライズ広告のみを配信する設定としています。

#### RevenueCat（アプリ内課金管理）
本アプリでは、プレミアムプランの購入状態を管理するために RevenueCat, Inc. が提供する RevenueCat を利用しています。RevenueCat は購入状態の確認、購入履歴の復元、プレミアム機能の有効化のために必要な情報を処理する場合があります。

Firebase Analytics へ送信する購入関連イベントは、購入完了状態や購入導線の状態に限定します。RevenueCat user ID、Apple transaction ID の生値、レシート、商品 payload、RevenueCat SDK Key は Firebase Analytics へ送信しません。

RevenueCat のプライバシーポリシー: [https://www.revenuecat.com/privacy](https://www.revenuecat.com/privacy)

### トラッキングについて

本アプリは、Firebase Analytics のデータや広告識別子を、他社のアプリや Web サイトをまたいでユーザーを追跡する目的では使用しません。そのため、本アプリでは App Tracking Transparency の許可ダイアログを表示しません。

---

## 2. 情報の利用目的

収集した情報は以下の目的にのみ利用します。

- 学習進捗の管理・表示（正答率、今日の学習記録、苦手科目の分析）
- アプリ設定の保持
- アプリの利用状況分析、品質改善、機能改善
- 広告の配信（無料ユーザーのみ）
- アプリ内課金の購入状態の確認、復元、プレミアム機能の有効化

---

## 3. 情報の第三者提供

本アプリは、法令に基づく場合を除き、ユーザーの情報を第三者に提供・販売・共有することはありません。

---

## 4. 情報の保管と削除

学習データはお使いの端末内にのみ保存されます。アプリ内の「設定」→「学習データをリセット」から、回答履歴および苦手フラグをいつでも削除できます。アプリをアンインストールすることで、すべてのローカルデータが削除されます。

---

## 5. 未成年者の利用について

本アプリは特定年齢層を対象とした利用制限は設けていませんが、未成年者が利用する場合は保護者の同意のもとでご利用ください。

---

## 6. プライバシーポリシーの変更

本プライバシーポリシーは、法令の改正やサービス内容の変更に応じて予告なく改定する場合があります。改定後のポリシーは本ページに掲載した時点から効力を生じるものとします。
